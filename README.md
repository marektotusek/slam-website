# SLAM website

The site for slamproduction.com. Netlify deploys every push to `main` automatically.

To change the site, edit `index.html` and push to `main`.

## Forms
The estimate form (`estimate`) and the contact window (`contact`) send to Netlify Forms.
Submissions appear in Netlify under Forms, and email alerts go to contact@slamproduction.com
(set under Forms → Form notifications). Form detection must stay enabled in Netlify.
